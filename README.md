# Unload On Demand

This add-on (extension) is to unload all other tabs at once. It provides two buttons: **'Unload Others'** and **'Unload Others (Force)**.

#### Unload Others

This button unloads all other tabs except media playing ones (which are not muted).

#### Unload Others (Force)

This button unload all other tabs even if they are playing media.
